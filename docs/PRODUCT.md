# Product

## Register

product

## Users

A private, single user captures links quickly, then returns later to decide what is
useful. Most sessions are short and may happen on a phone.

## Product Purpose

Link Nest is a personal knowledge inbox, not a bookmark warehouse. Success means
more eligible links receive a meaningful revisit: a note, useful decision, or
archive after enough time for genuine reflection.

## Brand Personality

Calm, focused, and familiar. The interface should feel like a lightweight native
utility that gets out of the user's way.

## Anti-references

- Statistics-first dashboards
- Gamified productivity tools
- AI-heavy knowledge systems
- Dense bookmark managers with folders and configuration everywhere

## Design Principles

- Put the next useful decision before secondary information.
- Keep capture fast and correction close at hand.
- Use familiar controls and direct language.
- Show only enough information to make the current decision.
- Add infrastructure only after real use proves the need.

## Accessibility & Inclusion

Support keyboard navigation, visible focus, semantic HTML, reduced motion, clear
status text that does not rely on color alone, and responsive phone layouts.
